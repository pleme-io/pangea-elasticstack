# pangea-elasticstack

Auto-generated typed Elastic Stack Terraform resource functions for the Pangea IaC DSL.
All resource code is generated by `terraform-schema-importer` from the Elastic
Terraform provider schema.

## Generation

```bash
terraform-schema-importer generate \
  --schema schema.json \
  --provider "registry.terraform.io/elastic/elasticstack" \
  --provider-name elasticstack \
  --output-dir .
```

## Resources: 52

All resources use the `define_resource` DSL with `Dry::Struct` type validation.
Module: `Pangea::Resources::Elasticstack`, prefix: `elasticstack_`.

## Regeneration

1. Update the provider version in a Terraform workspace
2. Run `terraform init && terraform providers schema -json > schema.json`
3. Run the generate command above
4. Run `bundle exec rspec` to validate
5. Commit the updated files

## Dependencies

pangea-core ~> 0.2, terraform-synthesizer ~> 0.0.28, dry-types ~> 1.7,
dry-struct ~> 1.6. Ruby >= 3.3.
